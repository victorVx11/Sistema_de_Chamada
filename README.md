# Sistema de Chamados

Projeto em Python para gerenciar chamados pelo terminal, desenvolvido para praticar lógica de programação.

## Funcionalidades

- Cadastro de chamados com ID, título, descrição e prioridade.
- Validação de campos vazios e prioridades.
- Listagem de chamados.
- Encerramento pelo ID.
- Verificação de chamados já encerrados.

## Como executar

Com o Python 3 instalado, abra o terminal na pasta do projeto e execute:

python main.py

## Tecnologias

- Python 3

## Limitação atual

Os chamados ficam na memória e são perdidos ao fechar o programa.

## Próxima melhoria

Salvar os chamados em arquivo ou banco de dados.
